# Tema Nuvemshop – Loja

Tema original (home, categoria, produto, carrinho, página, 404).

## Como instalar
1. Compacte o conteúdo (config, layouts, snipplets, static, templates) em um `.zip` na raiz.
2. Painel Nuvemshop → Design → Personalizar → Opções avançadas → Importar tema (ou use o Nuvemshop Theme CLI / Partners).
3. Personalize cores, banner e textos em "Personalizar".

> Os nomes de tags Twig (`{% template_content %}`, `{% head_content %}`, `product_image_url` etc.) seguem a documentação da Nuvemshop, mas o tema ainda não foi testado numa loja real. Valide no ambiente de desenvolvimento e ajuste conforme erros do importador.
